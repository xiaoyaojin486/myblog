## 一、项目概述

个人博客系统，包含**前台展示端**（游客浏览文章）与**后台管理端**（管理员维护内容）两部分。

### 功能范围

**前台展示端（游客访问）**

| 功能     | 说明                                    |
| -------- | --------------------------------------- |
| 文章列表 | 分页展示已发布文章，支持按分类/标签筛选 |
| 文章详情 | Markdown 渲染、代码高亮、浏览量统计     |
| 文章搜索 | 关键字搜索                              |
| 分类导航 | 按分类查看文章                          |
| 标签云   | 按标签查看文章                          |
| 归档页   | 按时间线展示文章                        |
| 评论     | 文章评论（匿名提交，审核后展示）        |
| 关于页   | 个人介绍                                |
| 项目展示 | 个人项目卡片列表与详情（拓展功能）      |
| 最新动态 | 首页展示最新动态/最新文章（拓展功能）   |
| 热门排行 | 首页侧栏热门文章排行（拓展功能）        |
| 主题切换 | 日夜主题切换（拓展功能）                |
| 文章点赞 | 文章点赞，Redis 防重复（本期 demo）     |

**后台管理端（管理员）**

| 功能     | 说明                                   |
| -------- | -------------------------------------- |
| 登录认证 | JWT 登录，路由守卫                     |
| 文章管理 | 增删改查、发布/草稿、Markdown 编辑器   |
| 分类管理 | 分类增删改查                           |
| 标签管理 | 标签增删改查                           |
| 评论管理 | 评论审核、删除                         |
| 系统配置 | 站点信息配置                           |
| 图片上传 | 封面/插图上传至阿里云 OSS（本期 demo） |
| 项目管理 | 项目增删改查（拓展功能）               |
| 动态管理 | 动态发布与删除（拓展功能，方案 B）     |

## 二、总体架构

采用**多 Maven 模块单体架构**，按业务功能拆分模块，模块高内聚、低耦合。

### 模块划分

每个业务模块由「聚合 pom（`myblog-xxx`）+ 对外契约（`myblog-xxx-api`）+ 内部实现（`myblog-xxx-impl`）」三部分组成，impl 包路径为 `com.myblog.xxx`。

| 模块                                                               | 类型    | 职责                                                                                                                  |
| ------------------------------------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `myblog-parent`                                                    | pom     | 父工程，统一依赖版本（dependencyManagement），聚合所有子模块                                                          |
| `myblog-common`                                                    | jar     | 公共模块：`Result<T>`、`PageResult<T>`、全局异常、工具类、常量、枚举、JWT、安全配置。不依赖任何业务模块，不写业务逻辑 |
| `myblog-user`                                                      | pom     | 用户模块聚合：聚合 `myblog-user-api` 与 `myblog-user-impl`                                                            |
| `myblog-user-api`                                                  | jar     | 用户模块对外契约：`UserApi` 接口、DTO、VO                                                                             |
| `myblog-user-impl`                                                 | jar     | 用户模块实现：Controller、Service、Mapper、Entity、Convert（包路径 `com.myblog.user`）                                |
| `myblog-article / -api / -impl`                                    | pom/jar | 文章模块（同用户模块结构，后续创建）                                                                                  |
| `myblog-category`、`myblog-tag`、`myblog-comment`、`myblog-system` | pom/jar | 分类 / 标签 / 评论 / 系统配置模块（同用户模块结构，后续创建）                                                         |
| `myblog-file / -api / -impl`                                       | pom/jar | 文件模块（本期 demo：OSS 图片上传，同用户模块结构）                                                                   |
| `myblog-project`、`myblog-moment`                                  | pom/jar | 项目展示 / 最新动态模块（拓展功能，同用户模块结构）                                                                   |
| `bootstrap`                                                        | jar     | 唯一启动模块，聚合所有 `xxx-impl`，打包可执行 Jar                                                                     |

项目目录结构：

```
myblog-ai/
├── pom.xml                      # myblog-parent（父工程）
├── myblog-common/               # 公共模块
├── myblog-user/                 # 用户模块（业务聚合）
│   ├── pom.xml                  # myblog-user（pom，聚合下面两个子模块）
│   ├── myblog-user-api/         # 对外契约：com.myblog.user.api
│   └── myblog-user-impl/        # 内部实现：com.myblog.user
├── bootstrap/                   # 启动模块
└── sql/                         # 数据库脚本
```

### 依赖方向

```
bootstrap → 所有 xxx-impl

xxx-impl → 自身 xxx-api、common、其他模块 xxx-api

xxx-api → common

common → 不依赖任何业务模块
```

### 架构红线（禁止项）

- 禁止循环依赖
- 禁止跨模块直接依赖对方的 service、mapper、entity、impl
- 禁止跨模块直接访问数据库
- 禁止 common 依赖业务模块
- 禁止 xxx-api 依赖 xxx-impl
- 禁止在 api 接口或 Controller 上添加事务注解

### 跨模块调用规则

- 只能注入目标模块的 `XxxApi` 接口，本地接口调用
- 未来可平滑改为远程调用（`@FeignClient`）
- `XxxServiceImpl` 同时实现本地 `XxxService` 和 `XxxApi`

## 四、数据库设计

### ER 关系概览

```
sys_user（用户）      独立表

category（分类） 1 ──── N article（文章）
tag（标签）      N ──── N article（文章）   通过 article_tag 关联
article（文章）  1 ──── N comment（评论）   comment 支持 parent_id 自关联（楼中楼）
sys_config（配置）    独立表

project（项目）       独立表（拓展功能）
moment（动态）        独立表（拓展功能，可选方案 B）
```

### 建表 SQL

```sql
-- 用户表
CREATE TABLE sys_user (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    username    VARCHAR(50)  NOT NULL UNIQUE COMMENT '用户名',
    password    VARCHAR(100) NOT NULL COMMENT '密码(加密)',
    nickname    VARCHAR(50)  COMMENT '昵称',
    avatar      VARCHAR(255) COMMENT '头像URL',
    email       VARCHAR(100) COMMENT '邮箱',

    update_time DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

-- 文章表
CREATE TABLE article (
    id           BIGINT PRIMARY KEY AUTO_INCREMENT,

    summary      VARCHAR(500) COMMENT '摘要',
    cover_image  VARCHAR(255) COMMENT '封面图',
    category_id  BIGINT       COMMENT '分类ID',
    view_count   INT          DEFAULT 0 COMMENT '浏览量',
    like_count   INT          DEFAULT 0 COMMENT '点赞数',
    status       TINYINT      DEFAULT 0 COMMENT '状态:0草稿,1已发布',

    update_time  DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

-- 分类表
CREATE TABLE category (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,

    update_time DATETIME    DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

-- 标签表
CREATE TABLE tag (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,

-- 文章-标签关联表

    remark       VARCHAR(255) COMMENT '备注'

-- 项目展示表（拓展功能）
CREATE TABLE project (
    id          BIGINT PRIMARY KEY AUTO_INCREMENT,
    name        VARCHAR(100) NOT NULL COMMENT '项目名称',
    description VARCHAR(500) COMMENT '项目简介',
    content     LONGTEXT     COMMENT '详细介绍(Markdown)',
    cover_image VARCHAR(255) COMMENT '封面图',
    tech_stack  VARCHAR(200) COMMENT '技术栈(逗号分隔，如 Vue3,Spring Boot,MySQL)',
    github_url  VARCHAR(255) COMMENT '源码地址',
    demo_url    VARCHAR(255) COMMENT '演示地址',
    sort        INT          DEFAULT 0 COMMENT '排序(越小越靠前)',
    status      TINYINT      DEFAULT 1 COMMENT '状态:0下架,1上架',
    create_time DATETIME     DEFAULT CURRENT_TIMESTAMP,
    update_time DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP

    status      TINYINT       DEFAULT 1 COMMENT '状态:0隐藏,1显示',
    create_time DATETIME      DEFAULT CURRENT_TIMESTAMP
```

## 六、后端关键设计要点

### 分层职责

| 层         | 职责                                                                                         | 禁止                                                       |
| ---------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Controller | 接收请求、参数校验、调用 Service、返回 `Result<VO>` / `Result<PageResult<VO>>`               | 不写业务逻辑，不直接调用 Mapper                            |
| Service    | 业务逻辑、事务、编排、权限校验；调用 Mapper 与其他模块 API；负责 DTO 转 Entity、Entity 转 VO | 事务注解 `rollbackFor = Exception.class` 只加在 Service 层 |
| Mapper     | 只负责数据库访问                                                                             | 不写业务逻辑，禁止 `SELECT *`（必须明确字段）              |
| Entity     | 对应数据库表，只在 Service/Mapper 内部使用                                                   | 不返回前端，严禁出现在 xxx-api 中                          |
| Convert    | DTO ↔ Entity、Entity ↔ VO 转换，补全审计字段、状态描述、脱敏字段                             | 禁止在 Controller 或 Mapper 中手动转换                     |

### ServiceImpl 双重实现

```java
// article-impl
@Service
public class ArticleServiceImpl implements ArticleService, ArticleApi {

    @Override
    @Transactional(rollbackFor = Exception.class)
    public Result<ArticleVO> create(ArticleCreateDTO dto) {
        // DTO → Entity（通过 Convert）
        ArticleEntity entity = ArticleConvert.INSTANCE.toEntity(dto);
        entity.setStatus(0); // 草稿
        articleMapper.insert(entity);
        // Entity → VO（通过 Convert）
        return Result.success(ArticleConvert.INSTANCE.toVO(entity));
    }

    // ArticleApi 接口方法（供其他模块调用）
    @Override
    public ArticleVO getById(Long id) {
        ArticleEntity entity = articleMapper.selectById(id);
        return ArticleConvert.INSTANCE.toVO(entity);
    }
}
```

### 跨模块调用

```java
// article-impl 中调用 category-api
@Service
public class ArticleServiceImpl implements ArticleService, ArticleApi {

    @Autowired
    private CategoryApi categoryApi;  // 只能注入 Api 接口

    public ArticleVO getDetail(Long id) {
        ArticleEntity article = articleMapper.selectById(id);
        ArticleVO vo = ArticleConvert.INSTANCE.toVO(article);
        // 通过 Api 接口获取分类信息，禁止直接访问 category 数据库
        vo.setCategoryName(categoryApi.getNameById(article.getCategoryId()));
        return vo;
    }
}
```

### Axios 请求封装（src/api/request.js）

```js
import axios from "axios";
import { ElMessage } from "element-plus";
import router from "@/router";

const request = axios.create({
  baseURL: "/api",
  timeout: 10000,
});

// 请求拦截：携带 Token
request.interceptors.request.use((config) => {
  const token = localStorage.getItem("token");
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});

// 响应拦截：统一处理 Result<T>
request.interceptors.response.use(
  (response) => {
    const res = response.data;
    if (res.code === 200) return res.data; // 直接返回 data
    ElMessage.error(res.message || "请求失败");
    return Promise.reject(res);
  },
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem("token");
      router.push("/admin/login");
    }
    return Promise.reject(error);
  },
);

export default request;
```

### 11.3 热门文章排行（article 模块扩展）

**阶段一：MVP（直接查库，低流量适用）**

```sql
SELECT id, title, view_count, like_count
FROM article
WHERE status = 1
ORDER BY view_count DESC, like_count DESC
LIMIT #{limit};
```

**阶段二：Redis 计数 + ZSET 排行（流量上来后）**

| 项                   | 设计                                                                             |
| -------------------- | -------------------------------------------------------------------------------- |
| 浏览量计数           | 文章被浏览时 `HINCRBY article:view {articleId} 1`                                |
| 总榜                 | `ZINCRBY article:hot:total 1 {articleId}`                                        |
| 周榜                 | `ZINCRBY article:hot:week:{yyyy-WW} 1 {articleId}`，按周分 key                   |
| 定时同步             | `@Scheduled` 每 5 分钟将 Redis 计数批量回写 MySQL `view_count`，清理过期周榜 key |
| 热度公式（可选加权） | `score = view * 1 + like * 5`                                                    |

**接口**：`GET /api/article/hot?limit=10&range=total|week`

**前端**：首页侧栏 `HotRank.vue` 组件（Tab 切换总榜/周榜，前三名特殊样式）

### 11.4 日夜主题切换（纯前端，零后端改动）

现有依赖 Element Plus 2.8.4 自带 dark 主题，无需新增依赖。

**实现步骤**

1. `main.js` 引入：`import 'element-plus/theme-chalk/dark/css-vars.css'`
2. 切换方式：`document.documentElement.classList.toggle('dark')`
3. 自定义 CSS 变量（`styles/theme.scss`）覆盖博客前台样式：

```scss
:root {
  --blog-bg: #ffffff;
  --blog-text: #333333;
  --blog-card-bg: #f7f8fa;
}
html.dark {
  --blog-bg: #1a1a1a;
  --blog-text: #e5e5e5;
  --blog-card-bg: #242424;
}
```

4. Pinia `store/theme.js`：

| 项           | 设计                                                 |
| ------------ | ---------------------------------------------------- |
| state        | `isDark`                                             |
| actions      | `toggleTheme()`、`initTheme()`                       |
| 持久化       | localStorage（key：`blog-theme`）                    |
| 初始值优先级 | localStorage → 系统偏好 `prefers-color-scheme: dark` |

5. 切换入口：顶部导航 `TheHeader.vue` 右侧主题按钮（太阳/月亮图标）

### 11.6 文章点赞（article 模块扩展，本期 demo）

- **匿名标识**：访客以「IP + User-Agent 哈希」标识（博客无登录体系）
- **判重**：Redis Set `article:like:{articleId}` 存标识，TTL 24h；重复点赞不重复计数，直接返回当前点赞数
- **计数**：`HINCRBY article:like:count {articleId} 1`；点赞数由定时任务批量回写 MySQL `like_count`（与浏览量同步任务共用）
- **接口**：`POST /api/article/{id}/like`，返回最新点赞数
- **前端**：文章详情页点赞按钮；localStorage 记录已赞状态，防止刷新后重复点击

### 11.7 图片上传（file 模块 + 阿里云 OSS，本期 demo）

- **后端**：新增 `file-api` + `file-impl`，依赖 `aliyun-sdk-oss`
- **上传流程**：接收 `MultipartFile` → 校验类型（jpg / png / gif / webp）与大小（≤10MB，与 yaml 中 `multipart` 限制一致）→ 生成 objectKey（`blog/yyyy/MM/{uuid}.{ext}`）→ 上传 OSS → 返回可访问 URL（优先自定义域名 `OSS_DOMAIN`，否则 bucket 默认域名）
- **接口**：`POST /api/admin/file/upload`；`DELETE /api/admin/file?objectKey=`（校验 objectKey 必须以 `blog/` 开头，防止越权删除）
- **配置**：`aliyun.oss.*` 全部来自 `.env`（见「六、后端关键设计要点 → 配置文件设计」）
- **前端**：`components/ImageUpload.vue` 封装 `el-upload`，用于文章封面、Markdown 正文插图、动态配图

## 十二、后续拓展路线图

以下功能暂未纳入本期开发，按优先级逐步实施：

| 功能         | 涉及模块                   | 优先级 | 说明                                        |
| ------------ | -------------------------- | ------ | ------------------------------------------- |
| 文章目录 TOC | 前端                       | 中     | 从 Markdown 提取标题树，滚动高亮当前章节    |
| 邮件订阅     | subscribe-api/impl         | 中     | 新文章发布后邮件通知订阅者                  |
| RSS 订阅     | article 扩展               | 中     | 生成 feed.xml，供阅读器订阅                 |
| 访问统计     | stat-api/impl              | 中     | PV/UV 记录 + ECharts 后台仪表盘             |
| 友链模块     | friend-api/impl            | 中     | 友链申请 + 审核流程                         |
| 留言板       | 复用 comment 或独立模块    | 低     | 独立于文章的留言                            |
| 全文搜索     | article 扩展               | 低     | 先 MySQL LIKE，数据量大再升级 Elasticsearch |
| SEO 预渲染   | 前端 vite-ssg              | 低     | 静态预渲染，利于搜索引擎收录                |
| 定时任务     | bootstrap 或独立 task 模块 | 低     | 统计同步、排行重建、过期数据清理            |

**实施注意**

1. 每新增业务模块（project / moment / friend / subscribe / stat 等）都必须创建 `xxx-api` + `xxx-impl`，并在父 POM 与 bootstrap 注册
2. 跨模块调用只能注入 `XxxApi`，禁止跨模块访问数据库
3. 定时任务放 bootstrap 或独立模块，注意不能反向依赖业务模块 impl

## 附录：开发流程强制要求

1. 新增业务模块必须创建 `xxx-api` 和 `xxx-impl`，并在父 POM 和 bootstrap POM 中注册
2. 跨模块调用必须通过 `xxx-api`，禁止 import 其他模块的 impl 包
3. 对外返回必须使用 common 中的 `Result<T>` 或 `PageResult<T>`
4. 异常由 common 中的全局异常处理器统一处理
5. 对象转换必须通过 Convert 层，禁止在 Controller 或 Mapper 中手动转换
6. 修改 common 或 xxx-api 后，先执行 `mvn install`
7. 事务注解只加在 xxx-impl 的 Service 方法上，`rollbackFor = Exception.class`
8. 禁止循环调用（如 article-impl 调 category-api，category-impl 不能再调 article-api）
